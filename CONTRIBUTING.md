# Contributing

Thank you for your interest in improving this demo! To keep the project easy to run in interview settings, please follow these guidelines:

1. Create and activate a Python 3.10+ virtual environment.
2. Install development dependencies with `pip install -r requirements.txt`.
3. Enable the formatting and linting hooks via `pre-commit install`.
4. Run `make lint` and `make test` before submitting changes.
5. Document noteworthy updates in `CHANGELOG.md`.

We welcome enhancements that improve clarity, reproducibility, or robustness of the stabilization pipeline.
